## 3. STEP-BY-STEP RECOVERY PLAYBOOK

### Scenario A: Flat Datastore Recovery (Local / Staging)
1. Stop running Next.js instance:
   `pnpm dev --stop` or kill the active Node process.
2. Verify available snapshots in `data/backups/`:
   `ls -la data/backups/`
3. Restore from the most recent known-good backup:
   `cp data/backups/ink-ivory-store-backup-2026-11-20T06-04-18-989Z.json data/ink-ivory-store.json`
4. Verify checksum against this document:
   `sha256sum data/ink-ivory-store.json`
5. Restart application:
   `pnpm dev`

### Scenario B: PostgreSQL Cloud Recovery (Production)
1. Provision target PostgreSQL database instance.
2. Apply Prisma schema DDL:
   `npx prisma db push` or `npx prisma migrate deploy`
3. Execute the validated SQL seed script:
   `psql "$DATABASE_URL" -f prisma/seed_data.sql`
4. Confirm record counts in PostgreSQL:
   ```sql
   SELECT count(*) FROM "Template";
   SELECT count(*) FROM "Draft";
   SELECT count(*) FROM "Publication";
   ```
5. Switch DNS / traffic to the restored instance.
