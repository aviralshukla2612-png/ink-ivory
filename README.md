# Ink & Ivory — Digital Wedding Invitations

> Bespoke, cinematic digital wedding invitation web pages and event experiences.

Ink & Ivory transforms traditional wedding invitations into interactive, full-screen digital celebrations. Featuring royal architectural atmospheres, GSAP-powered transitions, Lenis smooth scrolling, authentic Shehnai & Sitar melodies, and configurable multi-ceremony itineraries.

---

## ✨ Features

- **15-Scene Cinematic Storytelling**: From preloader to royal entrance, ceremonial deep-dives, family blessings, and riverside wish lanterns.
- **Physical Double-Door Gate Opening**: Master GSAP timeline coordinating independent 3D door swings and light blooms.
- **Dedicated Ceremony Chapters**: Tailored environments for Haldi, Mehendi, Sangeet, Wedding (Saat Phere), and Reception.
- **100% Configurable Wedding Data**: Reusable data model (`weddingData.js`) for couple details, itineraries, venues, and blessings.
- **Responsive Architecture**: Photorealistic landscape framing optimized across widescreen desktop, tablet, and mobile devices.
- **Interactive Extras**: Real-time wedding countdown, `.ics` calendar download, Google Maps integration, and wish lantern release.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: JavaScript / React 19
- **Styling**: Tailwind CSS
- **Animation**: GSAP, GSAP ScrollTrigger, Lenis Smooth Scroll, Framer Motion
- **Icons**: Lucide React
- **Audio**: HTML5 Audio API with user-interaction playback control

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
pnpm install
```

### 2. Run the Development Server
```bash
pnpm run dev
```

Open [http://localhost:3000](http://localhost:3000) for the main portal or [http://localhost:3000/template-01](http://localhost:3000/template-01) for the royal wedding invitation experience.

### 3. Build for Production
```bash
pnpm run build
```
